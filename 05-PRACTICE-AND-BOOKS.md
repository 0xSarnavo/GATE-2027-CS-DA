# Practice papers and books

## Free official PDF collection

The paper PDFs are in papers/CS and papers/DA where download succeeded. Each available answer key is named beside its paper. Use the source index below if an individual PDF is missing.

- CS: ten exam years, 2017–2026. Some years have multiple CS sessions; use both if you have time.
- DA: all actual exam years, 2024–2026. DA was introduced in 2024, so a ten-year DA set does not exist.
- DA sample paper: official 2024 sample in papers/DA if downloaded.
- Older CS papers may contain topics outside the 2027 syllabus. Check syllabus/CS-2027.pdf before investing in a question.

Official archives:
- 2026 papers and keys: https://gate2026.iitg.ac.in/QPs-answer-keys.html
- 2021–2025 papers and keys plus 2007–2025 bulk archive: https://gate2026.iitg.ac.in/download.html
- 2017–2023 archive: https://gate2024.iisc.ac.in/download/
- 2018 official CS PDF: https://gate.iitk.ac.in/GATE2023/doc/papers/2018/cs_2018.pdf
- 2017 official CS PDF: https://gate.iitk.ac.in/GATE2023/doc/papers/2017/cs_2017.pdf
- DA sample: https://gate2024.iisc.ac.in/wp-content/uploads/2023/10/DataScienceAISampleQuestionPaper.pdf

## How to use the papers

During October–December, use older CS papers as a topic-wise question bank. From January, hold out 2024–2026 CS/DA papers for timed 3-hour sessions. If a recent paper was already used for topic practice, use another old paper or a mock for a clean timed assessment. After each attempt, spend at least 2 hours analysing errors before another paper.

Track paper, date, score, time lost, wrong answers, guessed answers, and three topics to repair. Use the blank CSV file in this folder.
